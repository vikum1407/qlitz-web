# API Reference

The Qlitz REST API gives you programmatic access to all platform data — projects, test runs, releases, frameworks, and more. The same API powers the Qlitz dashboard.

## Base URL

```
https://your-qlitz-instance.com
```

For local self-hosted installations the default base URL is `http://localhost:3000`.

## Authentication

All API requests require a bearer token in the `Authorization` header:

```http
Authorization: Bearer <your-api-token>
```

Tokens are generated in **Project Settings → API Tokens**. Tokens are scoped to a project — a token issued for Project A cannot access Project B's endpoints.

## Request format

All request bodies must be JSON. Set the `Content-Type` header on requests that include a body:

```http
Content-Type: application/json
```

## Response format

All responses are JSON. Successful responses return the requested resource or an array of resources directly:

```json
{
  "id": "clx123abc",
  "name": "My Project",
  "createdAt": "2026-01-15T10:30:00.000Z"
}
```

## Error format

Errors return a consistent shape across all endpoints:

```json
{
  "statusCode": 404,
  "error": "Not Found",
  "message": "Project not found"
}
```

## Pagination

List endpoints return paginated results. Pass `page` and `limit` as query parameters:

```
GET /projects?page=1&limit=20
```

Paginated responses include a `meta` object:

```json
{
  "data": [...],
  "meta": {
    "total": 84,
    "page": 1,
    "limit": 20,
    "totalPages": 5
  }
}
```

## Timestamps

All timestamps are returned as ISO 8601 strings in UTC:

```
2026-01-15T10:30:00.000Z
```
