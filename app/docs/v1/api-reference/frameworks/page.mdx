# Frameworks API

## Generate a framework

```http
POST /projects/:projectId/framework/generate
```

Triggers framework generation for the project using the provided configuration. Generation runs server-side and is typically complete within a few seconds.

**Request body**

```json
{
  "framework": "playwright",
  "language": "typescript",
  "baseUrl": "https://portal.yourapp.com",
  "requirementIds": ["REQ-001", "REQ-002", "REQ-042"],
  "environmentVariables": {
    "TEST_USER": "qa@yourapp.com"
  }
}
```

## List generations

```http
GET /projects/:projectId/framework
```

Returns the generation history for the project — all previous framework generations with their configuration and status.

**Response**

```json
{
  "data": [
    {
      "generationId": "gen_abc123",
      "status": "completed",
      "framework": "playwright",
      "language": "typescript",
      "generatedAt": "2026-05-20T09:00:00.000Z"
    },
    {
      "generationId": "gen_xyz789",
      "status": "completed",
      "framework": "cypress",
      "language": "typescript",
      "generatedAt": "2026-04-10T11:30:00.000Z"
    }
  ]
}
```

## Get a generation

```http
GET /projects/:projectId/framework/:generationId
```

Returns the full configuration and status for a specific generation.

**Response**

```json
{
  "generationId": "gen_abc123",
  "status": "completed",
  "framework": "playwright",
  "language": "typescript",
  "baseUrl": "https://portal.yourapp.com",
  "requirementIds": ["REQ-001", "REQ-002", "REQ-042"],
  "generatedAt": "2026-05-20T09:00:00.000Z",
  "downloadUrl": "/projects/clx123abc/framework/gen_abc123/download"
}
```

## Download a generated framework

```http
GET /projects/:projectId/framework/:generationId/download
```

Returns the generated framework as a `.zip` archive. Use the `downloadUrl` from the generate or get response.

**Response headers**

```http
Content-Type: application/zip
Content-Disposition: attachment; filename="qlitz-playwright-typescript.zip"
```

**Example — download with curl**

```bash
curl -H "Authorization: Bearer <token>" \
  https://your-qlitz-instance.com/projects/clx123abc/framework/gen_abc123/download \
  -o framework.zip

unzip framework.zip -d my-test-project
```

## CI integration example

Trigger a generation and download the result in a single CI step:

```bash
# 1. Trigger generation
RESPONSE=$(curl -s -X POST \
  -H "Authorization: Bearer $QLITZ_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"framework":"playwright","language":"typescript"}' \
  https://your-qlitz-instance.com/projects/$PROJECT_ID/framework/generate)

# 2. Extract download URL
DOWNLOAD_URL=$(echo $RESPONSE | jq -r '.downloadUrl')

# 3. Download the archive
curl -H "Authorization: Bearer $QLITZ_TOKEN" \
  https://your-qlitz-instance.com$DOWNLOAD_URL \
  -o framework.zip
```
