# History

History gives you the complete run log for your project. Every test execution is recorded here with its full results, making it possible to track trends, compare runs, and understand how your suite health has changed over time.

## The run list

The History tab displays a chronological list of all runs for the project. Each row shows:

## Viewing a run in detail

Click any run to open its detail view, which shows:

- Full test-by-test results with expandable error output
- Coverage changes relative to the previous run — requirements that gained or lost coverage
- Insights generated for this run
- Links to any releases this run is associated with

From the detail view, you can open the **Replay** viewer for any recorded test case in the run.

## Comparing runs

Select two runs in the History list and click **Compare** to see a side-by-side diff:

- Tests that changed status (passing → failing or failing → passing)
- Requirements whose coverage status changed
- Pass rate and health score delta

Run comparison is especially useful after a deployment — select the run before and after the deploy to isolate the tests that the deployment affected.

## Filtering and searching

The run list can be filtered by:

- Date range
- Trigger source (manual, CI)
- Minimum pass rate
- Environment

Individual test results within a run can be searched by test case name, requirement ID, or error message.

## Retention

Run data is retained indefinitely by default. You can configure a retention window in project Settings to automatically archive runs older than a specified number of days, keeping the History list manageable for high-frequency projects.
