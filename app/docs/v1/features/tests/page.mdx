# Tests

The Tests tab is the integrated test runner inside Qlitz. You can trigger runs, monitor execution in real time, and view results — without leaving the platform or switching to a separate CI dashboard.

## Running tests

To start a test run:

1. Navigate to the **Tests** tab in your project
2. Select the test suite or individual test cases to run
3. Choose the target environment (configured in project Settings)
4. Click **Run**

Qlitz dispatches the run to the configured execution environment and begins streaming results back as tests complete.

## After a run completes

When a run finishes, Qlitz immediately:

- Updates the **Coverage** tab with new requirement coverage data
- Recalculates the **Readiness** score
- Runs the **Insights** analysis pass and updates the Insights panel
- Stores the run in **History**
- Makes the run available in **Replay** if recording was enabled

## Test case management

The Tests tab also provides a list view of all test cases in your project. From here you can:

- Filter by status, linked requirement, or tag
- Mark test cases as active or inactive
- View the requirement each test case is linked to in the RTM
- Manually trigger a single test case in isolation

## Environment configuration

Test environments (base URLs, credentials, environment variables) are managed in the project **Settings** tab. Multiple environments (e.g. staging, production) can be configured and selected at run time.
