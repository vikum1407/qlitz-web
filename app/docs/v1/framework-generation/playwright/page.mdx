# Playwright

Qlitz generates a complete Playwright automation framework with cross-browser support across Chromium, Firefox, and WebKit. Playwright is the only framework in Qlitz with full multi-language support — covering TypeScript, JavaScript, Java, Python, and C#.

## Generated project structure (TypeScript)

```
tests/
  *.spec.ts               ← test files linked to RTM requirements
pages/
  base/
    BasePage.ts           ← shared page object base class
  *.page.ts               ← one page object per application area

  fixtures.ts             ← Playwright test fixtures
```

## Page objects

Playwright page objects in Qlitz use the Locator API rather than raw selectors, which provides built-in auto-waiting and retry-ability. Each generated page object extends a typed `BasePage` that wraps common Playwright interactions.

```typescript
// Example: DashboardPage.ts (generated)
import { Page, Locator } from '@playwright/test';
import { BasePage } from './base/BasePage';

export class DashboardPage extends BasePage {
  private readonly newProjectButton: Locator;

  constructor(page: Page) {
    super(page);
    this.newProjectButton = page.getByTestId('new-project-btn');
  }

  async createProject(name: string) {
    await this.newProjectButton.click();
    await this.page.getByLabel('Project name').fill(name);
    await this.page.getByRole('button', { name: 'Create' }).click();
  }
}
```

## Configuration

The generated `playwright.config.ts` includes:

- Multi-browser project configuration (Chromium, Firefox, WebKit)
- Base URL from your Canvas configuration
- Qlitz results reporter
- Parallel execution settings
- Screenshot and video capture on failure (feeds Replay)

## Running the generated framework

```bash
# Install dependencies and browsers
npm install
npx playwright install

# Run all tests
npx playwright test

# Run in a specific browser
npx playwright test --project=firefox

# Run with trace viewer
npx playwright test --trace on

# Run against a specific environment
BASE_URL=https://staging.yourapp.com npx playwright test
```

## API testing with Playwright

Qlitz also supports Playwright for API automation. When you select Playwright (API) in the Canvas, the generated framework uses Playwright's `APIRequestContext` rather than a browser, producing a lightweight API test suite without browser overhead.
